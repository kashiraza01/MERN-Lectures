# Mid-Term Exam Starter

Partially built Vite + React 18 + Redux Toolkit + React Router v6 starter for the Monday mid-term practical exam.

## How to run

```bash
npm install
npm run dev
```

Open the URL printed by Vite (usually `http://localhost:5173`).

You should see a working navbar with **Home / Products / Cart** links and a basic home page. The Products and Cart pages contain placeholders that you will complete as part of the exam tasks.

## Other scripts

```bash
npm run build     # production build
npm run preview   # preview the production build
npm run lint      # run eslint
```

## Important

- **Do NOT commit `node_modules/`.** A `.gitignore` is already provided.
- Open `TASKS.md` for the list of exam tasks.
- Write your short answers in `ANSWERS.md`.
- Make a separate commit per task with a clear message (`task-1: fix counter bugs`, etc.).

## Stack

- Vite 5
- React 18
- React Router DOM 6
- Redux Toolkit 2 + React Redux 9
